# Discord Multitool

A multi-tool for Discord webhook management, user token utilities, group chats, and server information.

---

## Features

### Webhook Tools
- Webhook Deleter
- Webhook Spammer
- Webhook Editor
- Webhook Info

### User Tools
- User Token Checker
- User Token Nuker
- Group Chat Spammer

### Server Tools
- Bot Invite Generator
- Server Info

---

## Requirements

Python must be installed before using this tool.

**Download Python:**

https://www.python.org/downloads/

During installation, make sure to enable:

- Add Python to PATH

---

## Installation

### Option 1: Automatic Installation

1. Download the project.
2. Extract the archive.
3. Run:

```bat
setup.bat
```

The setup script will:
- Check your Python installation.
- Install the required dependencies.
- Launch the tool automatically.

### Option 2: Manual Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
python main.py
```

---

After completing the installation, launch the application using `setup.bat` or run it manually:
